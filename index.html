Продавец невидимВ сущности Unit нет seller_id в открытом виде — связь хранится отдельно, доступна только владелице. В «дереве инвайтов» никто не видит, что приглашённый им человек что-то продаёт или покупает: реферер видит лишь «одобрен».
Блок-лист продавцаПродавец вводит номера телефонов тех, кто не должен видеть лот (родня, партнёры, соседи). Хранятся только хэши; при матче лот просто не попадает в выдачу этому члену — без уведомлений обеим сторонам. Плюс галочки: «никому из моего дерева инвайтов», «никому с адресом в этом доме», «каждое раскрытие — вручную».
Проверка конфликтов перед L2Система сравнивает клиента и продавца: общая цепочка инвайтов, совпадение по хэшу телефона с блок-листом, один и тот же дом в анкете/адресе, общие показы. Конфликт → раскрытие только через владелицу с пометкой «почему».
Персональная ссылка на каждое раскрытиеОдноразовая, TTL, привязана к TG-id получателя; открытие с другого аккаунта → «это не ваша ссылка» + алерт владелице. Фото — через короткоживущие подписанные URL, EXIF вырезан, оригиналы не отдаются на скачивание.
Каталог — не витрина для любопытныхПо умолчанию член видит только match по своей анкете (≤ N лотов), остальное — через расширение анкеты, которое логируется. Лимит просмотров (например, 20 карточек/час) → мягкая пауза + сигнал владелице. ID лотов непредсказуемые, noindex, никакого bulk-экспорта и печати.
Аудит, а не иллюзия защитыСкриншот запретить нельзя — поэтому водяной знак с именем и телефоном на всём L1+ и полный лог «кто, что, когда, как долго, с какого устройства». Владелица видит по каждому лоту всех, кому он раскрыт, и может отозвать раскрытие — ссылка гаснет.
Две стороны анонимны на показеПродавец не присутствует; клиент для продавца — «покупатель №3, оценка “думаю”». Обратная связь идёт через владелицу.
GDPRМинимум ПД, хэшированные телефоны в блок-листах, срок хранения аудита в согласии, право отозвать — с пометкой, что лог раскрытий хранится как юридический след сделки.

Принципы каркаса
Закрытость как продуктГость видит ровно столько, чтобы захотеть внутрь: тизеры без адреса и цены, «N закрытых лотов под ваш запрос». Полный каталог — только членам.
Владелица = куратор, не витринаКаждый инвайт персональный, «Вас пригласила …» на входе, персональный менеджер = она сама. Никаких публичных форм «оставьте телефон» внутри кабинета.
Mobile-firstВход через Telegram, bottom-nav из 5 пунктов, sticky-CTA с ценой на карточке, фильтры в bottom sheet, шахматка листается горизонтально.
Юнит — первоклассная сущностьСтатус, экспозиция, история цены, план, вид. Один источник правды для клиента, шахматки и админки — двойной брони не бывает.
Сделка прозрачна обеим сторонамОдин timeline: клиент видит «что дальше», владелица — где застряло. Документы в data room под NDA с логом просмотров.
Всё считаетсяКаждая кнопка = событие с именем. Dashboard показывает воронку инвайт → активация → просмотр → показ → бронь и «горячих» клиентов.
